# D 题模型与任务步骤

第一问从组成预测违反度 V。第二问固定 NO2，在 52×52 个 A/B 对中选一个。第三问增加 O3/NO2/FO2 选择，共 8,112 个。后两问要求 QUBO、Kaiwu SDK、系数约束和逐项成本分析。

## 数据

| 前缀 | 行数 | 用途 |
|---|---:|---|
| 02 | 11,256 | 第一问训练 |
| 03 | 3,969 | 第一问验证与选模 |
| 04 | 3,703 | 仅组成的隐藏测试 |
| 06 | 15,225 | 02+03 的仅组成副本 |
| 07/08 | 2,704 / 8,112 | Q2/Q3 完整池 |
| 11/12 | 529 / 1,587 | Q2/Q3 blind 子集 |

分组单位为 (A,B)。A=B 合法，gap=0 表示金属性。第二、三问选定模型后用 02+03 重训。

偏离量依次为 e_form−0.21、1.4−gap、gap−3.1、5.73−vbm、cbm−4.50，每项为 max(0,偏离量/0.5) 的平方，V 是五项之和。题面给出严格条件 15 个与 V=0 的 19 个两种口径，优化按规定的惩罚和，并解释边界差异。CSV 六位小数会使 V 重算存在约 1e-5 误差。

## 第一问

输入采用 A/B/X 及组成可导出的元素属性。形成能、真实带隙、带边、晶格、真实惩罚和 V 在未知池没有提供，只能用于训练目标与诊断。A 与 B 保留位置区别。

已有探索为直接 V 回归、带隙混合、log1p 回归、五项惩罚分别预测。官方 03 作选模验证，近目标留出在 02 内实施。记录 MAE、BestV@B、阈值命中、第一名真实 V、单点选择遗憾。正式模型尚待冻结。

## 第二问

a、b 各为 52 个二进制变量，两边各选一个。完整池分数为 C_ij。

```math
E(a,b)=\sum_{ij}C_{ij}a_i b_j+
P_A(\sum_i a_i-1)^2+P_B(\sum_j b_j-1)^2.
```

说明矩阵约定、公共常数、缩放、罚系数与 Ising 转换。解码检查合法性后，用原始预测分数评价。穷举 2,704 个合法态作为基准。

## 第三问

联合基准可用 156 个 (A,X) 变量加 52 个 B，共 208 个变量。固定三个 X 分别求解也可覆盖完整池。

研究路线采用 C_ab=min_x V_hat(a,b,x)，再以 104 个变量求 A/B，恢复对应 X，并保留并列。用原始 8,112 个评分逐态检查最小值和最优集合。该方法适用于当前目标，额外约束需反映到候选集合。

11/12 仅是子集，编码必须约束成员关系，完整笛卡尔积模型会允许池外材料。完整池与 blind 结果分开报告。
