## 主要判断

原论文的核心公式、已存档候选与关键数值可复核。当前证据支持混合模型用于
近目标候选清单筛选，支持分块编码在给定预测表上的精确性；尚不足以证明
它是 Q2 单选的最佳模型，也不能证明新材料满足全部物理条件或存在硬件加速。
本轮没有为了提高结论强度而替换冻结预测或虚构新实验。

| 审查问题 | 修改及结果 |
|---|---|
| 单选与 top-50 指标不匹配 | 明确 Q2 单选验证中 property-first 更好；保留共同代理目标是实验可比性的选择，不是物理最优的证据 |
| 两种分数被直接比较 | 加入凸平方 hinge 损失下的 Jensen 不等式：对条件均值计算惩罚，与条件期望惩罚不同；该不等式不保证任意拟合模型的分数顺序 |
| 概率门控的解释 | 混合分数是近似条件期望构造；不是“满足全部条件”的校准概率 |
| 开发样本复用 | 强调 03 用于模型选择，分组/压力检查也不是完整嵌套的模型选择评估；不能据此推断隐藏零目标召回率 |
| QUBO 的贡献边界 | 明确先算全体代理分数，分块解决系数精度与原始分数恢复；不减少代理评估次数 |
| 量化并列状态 | 保留完整基态检索条件；增加仅返回任意整数基态时的块内原始损失上界 M/15，未命中基态时不适用 |
| 精确同分的规则不一致 | `solve.py` 在块内与全池验证统一按官方 ID 决胜；现有档案没有因此改变最终推荐 |
| 归一化边界 | 写明 min–max 公式及所有成本相等时的定义 |
| 计算成本 | 分开全池预测、求解、DFT 复测；没有 DFT 耗时数据，不能报告对应时间节省 |
| 章节措辞 | 将“failed alternative”改为中性的 property-first alternative，避免掩盖它在 Q2 的优势 |
| 复现范围 | 新增仅依赖 NumPy/pandas 的独立存档审计；明确本轮未重新训练模型、未重跑 SDK |

## 剩余研究局限

1. Q2 不同代理的首选变化仍需隐藏标签或独立 DFT 才能裁决。
2. 19 个严格隐藏零目标的召回率未知，V<1 的开发结果不能替代它。
3. 只比较两个训练种子不能量化完整的训练不确定性。
4. 只证明已试参数的整网量化失败，不能推论所有整网编码都失败。
5. 未测量 SPQC 真机、端到端设备耗时或新 DFT 计算，不报告这类性能。
